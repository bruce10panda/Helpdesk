Verbinden met GitHub

Deze pagina schrijft wijzigingen rechtstreeks naar de repository op GitHub. Daarvoor heb je een eigen GitHub-token nodig — dat is de echte beveiliging: alleen wie schrijftoegang tot de repo heeft, kan hier iets opslaan.

Hoe maak ik een token aan? (eenmalig)
  1. Ga naar github.com/settings/personal-access-tokens/new en log in met een GitHub-account dat schrijftoegang heeft tot deze repository.
  2. Geef het token een naam, bijv. "Helpdesk beheer".
  3. Kies bij Repository access voor "Only select repositories" en selecteer deze repo (Helpdesk-uren).
  4. Zet bij Permissions → Repository permissions → Contents op Read and write. Meer heeft deze pagina niet nodig.
  5. Klik op "Generate token" en kopieer de token (begint met github_pat_…).
  6. Plak hem hieronder. Hij wordt alleen in dit browsertabblad onthouden (niet opgeslagen), en gaat rechtstreeks naar GitHub — nooit ergens anders naartoe.

Verbonden met GitHub

Rooster

Klik op een naam in een vak om diegene dat lesuur te verwijderen. Gebruik het keuzemenu om iemand toe te voegen.

Helpdeskers

Voeg een nieuwe helpdesker toe of verwijder iemand. Verwijderen haalt diegene ook overal uit het rooster.

Niet beschikbaar

Geef aan dat iemand op een bepaalde datum een bepaald lesuur niet beschikbaar is. Diegene verdwijnt dan automatisch dat lesuur van het rooster op de site — je hoeft het weekrooster hiervoor niet aan te passen.
